# 計算模型 V0.1

## 坐標與幾何

以底版趾端為 x=0、基底底面為 y=0。牆背面垂直，牆身前面自底厚縮至頂厚。B=趾+底部牆厚+踵；H土壓=牆身高度+底版厚。

使用踵端的虛擬牆背進行外部穩定分析，因此土壓高度取地表至基底。牆體與踵上背填為自由體內重量；未考慮底版趾端覆土。重力式牆是同一幾何系統的重型梯形牆，示範踵長為 0，不代表任意牆背傾斜的重力牆均支援。

所有值以每延米：m、kN/m、kN·m/m、kPa。角度输入為度，計算轉成弧度。

## 重量及作用點

底版 W=B·t·γc，重心=(B/2,t/2)。牆身使用四點多邊形面積及重心公式。踵上土 W=踵·牆身高·γs，重心=(趾+牆底厚+踵/2,t+牆身高/2)。

均佈地表載重的穩定重量不採計，以免取得不持續荷載的有利效果；側向不利效果採計。地震慣性計入所有上述自重，未加入均佈地表活載慣性。

## 土壓力

常時 Ka=tan²(45°−φ/2)，Pa=Ka·γ·H²/2，作用點 H/3。

地震 θ=atan[kh/(1−kv)]。水平乾土、垂直光滑牆背的限制版 M–O：

Kae=cos²(φ−θ)/{cos²θ·[1+√(sinφ·sin(φ−θ)/cosθ)]²}。

Pae=Kae·γ·H²·(1−kv)/2。靜態 Pa 作用於 H/3，差值 ΔP=Pae−Pa 作用於 **0.6H**，此為明示模型假設，並非宣稱為所有規範的唯一指定值。ΔP 如為負保留其代數符號，不擅自取絕對值。均佈載重側壓 Pq=Kae·q·H，作用點 H/2。

kv 正值表示減少有效重力。|kv|非零時計算正負兩個方向，介面分別顯示，應逐項取不利工況。θ≥φ 的非零 kh 工況為未支援，仍保留常時計算。未考慮動水壓、非水平填土及牆背摩擦。

## 穩定與接地

N=ΣW·(1−kv)，Mr=ΣW·x·(1−kv)。水平慣性 Hi=kh·ΣW，慣性力矩 Mi=Σkh·W·y。

Mo=Pa·H/3+ΔP·0.6H+Pq·H/2+Mi。

FS傾覆=Mr/Mo；FS滑動=μN/(Pae+Pq+Hi)。未採計基底凝聚力或前方被動阻力。

xR=(Mr−Mo)/N，e=B/2−xR。

- |e|≤B/6：全底接觸，qmax,min=N/B·(1±6|e|/B)。
- B/6<|e|<B/2：無拉力三角接觸，b=3·min(xR,B−xR)，qmax=2N/b、qmin=0。
- xR 在基底之外或 N≤0：失穩，不輸出虛構的壓力值。

壓力模型與偏心距合規分開判定。岩盤採 |e|≤B/4 門檻，也不假設可以承受拉力，仍適用部分接觸壓力模型。

## 法規門檻與承載力

核對來源：[農業部水土保持技術規範](https://law.moa.gov.tw/LawContent.aspx?id=FL014521)，頁面修正日 114/05/07，於 2026/10/11 檢視第 120 條。

| 檢核 | 常時 | 地震 |
|---|---|---|
| 滑動 FS | ≥1.5 | ≥1.2 |
| 傾覆 FS | ≥2.0 | ≥1.5 |
| 土層偏心距 | ≤B/6 | ≤B/6 |
| 岩盤偏心距 | ≤B/4 | ≤B/4 |
| qmax | ≤使用者 gross qa | ≤使用者 gross qa |
| qult/qmax | ≥3.0 | ≥3.0 |

第 120 條承載安全係數要求未在該項另列地震折減值，因此本版兩工況均採 3.0；不自動推導 qa=qult/3，亦不把 qa/qmax 稱為承載 FS。使用者輸入的 qa/qult 必須對應基底形狀、偏心／傾斜荷載及正確工況。若其源於未修正之一般地盤試驗，不能直接以本程式顯示通過代替地盤設計審查。

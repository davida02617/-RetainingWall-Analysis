# 計算模型 V0.3

適用法規、版次與修正對照見 [台灣法規檢討](TAIWAN-REGULATIONS.md)。Python 與 JavaScript 共同使用相同欄位、來源及模型中繼資料；數值實作另以跨語言及獨立手算測試驗證。

## 範圍與幾何

每延米，m、kN、kPa。僅乾燥、均質、無凝聚土、水平背填、垂直光滑虛擬牆背、可發展主動狀態。非零地下水、坡度、凝聚力或牆背摩擦直接拒絕。非均質、完全受限牆及地層滑動需另外建模。

B=toe+stem_bottom+heel；H=height+base_thickness。踵端為虛擬土壓面，自基底底面至填土頂。x 從牆趾起算，y 自基底底面起算。牆身為背面垂直梯形，以多邊形積分計算面積、重心；底版、牆身、踵上土重分別列示。有效露出高度獨立輸入，不能用 H 代替。

## 土壓

Ka=tan²(45°−φ/2)。θ=atan[kh/(1−kv)]，此 θ 為地震慣性角，與規範符號命名不同。

Kae=cos²(φ−θ)/{cos²θ[1+√(sinφ·sin(φ−θ)/cosθ)]²}。

這是 §7.3.4 Mononobe–Okabe 在牆面垂直、背填水平、牆摩擦為零時的化簡。θ≥φ 無可用解，回報 unsupported。Pa=0.5KaγH²；Pae=0.5KaeγH²(1−kv)；ΔP=Pae−Pa。保留 ΔP 的代數符號；作用點超出 0～H 時不使用此增量分配模型。

常時作用點 H/3。地震作用點依位移模式：

| 模式 | Pa 高度 | ΔP 高度 |
|---|---:|---:|
| 對牆底旋轉 | H/3 | 2H/3 |
| 滑移 | 0.42H | 0.48H |
| 對牆頂旋轉 | 0.55H | 0.55H |

kh=kv=0 時回復常時作用點。地震 kh、kv 需附工址與設計依據，本版不從地址自動產生地震係數。

均佈載重 q 按等值重力載重：Pq=Kae·q·H·(1−kv)，本模型均佈側壓作用於 H/2。q>0 時計算：(a)側壓但不計踵上有利重量；(b)無載重；(c)側壓加 q·heel 垂直重量（heel>0），重量作用在踵中央、y=H，地震亦計其等值質量慣性。施工、交通衝擊、集中／線載重與其他載重組合需另行檢討。

## 力、力矩與接地

N=ΣW(1−kv)；Mr=ΣWx(1−kv)。Mo 為土壓與均佈載重側壓力矩，加上 ΣkhWy。水平力為 Pae+Pq+ΣkhW；FS滑動=μN/水平力；FS傾覆=Mr/Mo。無被動土壓或黏著加成。

xR=(Mr−Mo)/N；e=B/2−xR。N≤0 或 xR 在基底外為失穩；全接觸 qmax,min=N/B(1±6|e|/B)。超過中間三分之一採部分接觸：b=3min(xR,B−xR)，qmax=2N/b，qmin=0。壓力平衡與法規偏心距各自判定。

qa、qult 是使用者提供、與基底條件和工況相符的 gross 值。地震欄位留空沿用常時，不自動提高。建築 FS=(qult−q0)/(qmax−q0)，q0 為開挖前覆土壓力；無有效正分母時待確認。水保模式核 gross 比值，同時適用取 gross、net 較不利者。qa 必須受沉陷限制，不能以 qa/qmax 當 FS；本版不自行建立地盤承載力公式。

## 判定與輸出

每項輸出 value、limit、operator、basis、status。建築嚴格「>」與水保「≥」分開；計算值不先四捨五入。包絡以 value/limit 的相對不利程度選取，保留控制工況 ID。缺資料、缺來源、法規未確認或無解，不得顯示通過；已可確認的不符合仍保留。

`static`、`seismic` 保留原有契約，新增 `additional_cases`、`envelope`、`regulation`、`references`、`height_review`、`outstanding`。舊 JSON 缺新增欄位時套用預設，不自動視為已確認。`overall_status` 固定 incomplete，RC／材料、排水、沉陷、液化及整體穩定另列待辦。

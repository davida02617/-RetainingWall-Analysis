# 工程工作區 UI 0.3.1

2026-10-11。依使用者要求，將擋土牆分析介面調整為工程計算軟體風格。

- 深藍灰工具列、白色工作面板、較緊湊的留白、清楚的區塊編號。
- 工程計畫與保存／匯入／匯出／摘要／計算書集中於上方工具列。
- 斷面頁籤顯示序號與總高；可跳至斷面圖、穩定檢核、待辦與依據。
- 左側輸入以參數符號、獨立單位、等寬數值及資料來源欄位組成。
- 右側斷面加入底版、牆身及背填材料填充、尺寸線、基底原點與常時土壓方向，另列 8 個幾何尺寸。圖形為幾何示意，非施工圖。
- 5 項控制工況卡片顯示計算值、單位、門檻及文字狀態，不只依顏色區分結果。
- 檢核表數值右對齊，條文來源置於項目下方，小螢幕表格可橫向捲動。
- 保留案件適用性、待補檢核與完整設計未完成的顯示。
- 窄螢幕改為單欄；手機輸入字體避免過小；加入鍵盤焦點、跳至內容與減少動態效果設定。
- 報告採白底列印；斷面 SVG 的圖樣／箭頭 ID 與操作畫面分開，避免引用衝突。

## 驗證範圍

JavaScript 語法檢查及資源同步檢查通過；26 個介面元素引用均對應實際 HTML ID，未有重複 ID。以應用程式繪圖函式產出 R2 SVG，檢查幾何與尺寸標註，並修正底版分段尺寸文字間距。

計算核心、法規門檻、公式、JSON 契約、瀏覽器保存鍵均維持 V0.3.0。Python 本機版與線上靜態資源同步；既有 CI 持續檢核 30 項測試。

Sites 指定的瀏覽器操作能力在此環境未提供；未完成真實瀏覽器整頁視覺、觸控與列印互動驗證。SVG 單圖檢查不能取代完整瀏覽器驗證。
